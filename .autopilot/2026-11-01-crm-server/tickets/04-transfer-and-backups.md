## Что должно заработать

Директор в «Настройках → Перенос» выбирает CSV листа «Остатки» и видит, сколько товаров, склеек с каталогом, остатков и резервов загрузится и что не разобралось. После «Загрузить» остатки фирмы заменяются, а в журнале склада появляется «Ввод остатков». Повторный перенос в день переезда не удваивает остатки. Так же загружаются клиенты: CSV контактов и CSV компаний из Битрикса, без дублей. До переноса склад показывает «нет данных», а не снимок 31.10. Сервер каждую ночь делает копию базы и хранит 30 последних. В «Настройках → Копии» директор скачивает любую копию, делает копию сейчас и восстанавливает базу.

## Критерии приёмки

- [ ] `Import.decode` различает UTF-8 и Windows-1251 (с BOM и без); `Import.parseCsv` — разделитель `;`, `,`, таб, кавычки, кавычка внутри, перевод строки в кавычках
- [ ] `Import.stockRows` на искусственном CSV формы листа «Остатки» (заголовок не в первой строке, разделы, пустые и текстовые клетки) даёт строки формы `STOCK_SNAPSHOT.rows` плюс `reserve`; файл без колонки названия, не CSV, пустой — `problems` с понятным текстом
- [ ] `Import.parseReserve`: «36шт автоношкин, 64 Алексей Н.» → `[{36, «автоношкин»}, {64, «Алексей Н.»}]`; «Петров» → в `rest`
- [ ] `Import.applyStock`: остатки заменены; на каждый товар с остатком — движение «Ввод остатков (перенос, дата)»; резервы с `note` и `imported: true`, без сделки; повторный перенос того же файла — те же id товаров, остатки и резервы не удвоились; товар без пары в каталоге — id по нормализованному названию
- [ ] В `SERVER` до переноса `Catalog.unpack` не берёт `STOCK_SNAPSHOT`: у товаров каталога «нет данных: остаток»; после — строки из `stockSheet`
- [ ] Примечание резерва видно в карточке товара и журнале (`Stock.reserveView` отдаёт `note`); резерв без сделки — «нет данных: сделка» и примечание
- [ ] `Import.clientRows`: контакты и компании Битрикса по колонкам из «Колонки переноса»; тип файла — по «Название компании»; нераспознанные колонки перечислены; строки без имени — `skipped`. `Import.applyClients`: повтор того же файла не плодит клиентов (ИНН > телефон > почта), недостающее дописано; «Ответственный» → менеджер по точному имени; `org` видно в карточке клиента «Компания: …»
- [ ] «Настройки → Перенос» (только `admin`, только `SERVER`): выбор файла → предпросмотр с числами → «Загрузить» → `POST /api/import/*` → итог; CSV не сохраняется ни на сервере, ни в `localStorage`; ошибка файла — текст, база не тронута
- [ ] Копии: в `CRM_BACKUP_HOUR` по `TZ` — `VACUUM INTO` в `data/backups/crm-ГГГГ-ММ-ДД.db`; хранится `CRM_BACKUP_KEEP` (30) последних, старые удаляются; копия, пропущенная из-за выключенного сервера, делается при старте
- [ ] «Настройки → Копии» (только `admin`, только `SERVER`): список (дата, размер), «Скачать», «Сделать копию сейчас», «Восстановить» с подтверждением; восстановление сперва делает копию текущей базы («перед восстановлением»), заменяет базу, перечитывает состояние, всем вкладкам — `reload`; не директору API копий — 403
- [ ] `node server/admin.js backups` и `restore <файл>` работают
- [ ] `node tools/build.js && node --test tests/` — зелёный
