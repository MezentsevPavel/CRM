## Что должно заработать

Кто открыл адрес CRM, не войдя, не видит ничего, кроме формы входа: ни каталога с ценами, ни остатков, ни демо-данных — даже в коде страницы. В рабочей версии в Настройках и в таблице прав ролей нет ни слова про почту, Telegram и MAX.

## Что нашла слепая приёмка (дословно по смыслу)

1. Страница, которую сервер отдаёт без входа, содержит весь каталог с ценами и снимок остатков от 2026-10-31 (строки вида «ИП: 98 шт»), плюс демо-данные в коде страницы. Видно любому, кто открыл адрес. Данные API без входа отдают 401.
2. В Настройках и в таблице прав ролей остались пункты про почту, Telegram и MAX (например `src/js/31-perms.js:17` «Писать клиентам в Telegram и MAX»).

## Критерии приёмки

- [ ] `GET /` без действующего сеанса: в ответе нет ни строк снимка каталога (название товара с ценой), ни строк снимка остатков (`src/js/11-stock-data.js`), ни демо-людей, клиентов и сделок из `SEEDS`. Форма входа работает: верный логин и пароль → страница перезагружается и открывается рабочая CRM. Тест: запрос без cookie не содержит трёх конкретных строк — по одной из снимка каталога, снимка остатков и демо-данных; запрос с cookie — содержит каталог (он нужен работе); после входа через API следующий `GET /` отдаёт полную страницу.
- [ ] Как это сделано — выбери сам, но без второй копии кода: например, сборка ставит метки вокруг снимков и демо-данных, а сервер без сеанса отдаёт страницу с вырезанными кусками; или отдельная страница входа, если форма входа берётся тем же кодом, а не переписанной копией. Демо-файл `crm-wind-solar.html`, открытый с диска, работает как прежде (существующие тесты).
- [ ] Снимок остатков от 31.10 в рабочей версии с сеансом: если он где-то показывается сотрудникам как остатки (а не только товары каталога), — не меняй, а напиши в CONCERNS, где именно.
- [ ] В рабочей версии (`SERVER`) в Настройках нет вкладок и пунктов про почту, Telegram и MAX, а в таблице прав ролей — строк про них. В демо-файле всё как было. Тест: в серверном режиме список вкладок настроек и строк таблицы прав не содержит «почт», «Telegram», «MAX»; в демо — содержит.
- [ ] `node tools/build.js && node --test tests/` — зелёный
