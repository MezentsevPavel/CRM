# 0012. Российский VPS с Caddy перед сервером; страница не ходит на внешние адреса

Заменяет часть 0001: Google Fonts больше не единственный внешний адрес страницы — внешних адресов нет.

## Контекст

Бриф: «сервер в России (152-ФЗ)», вход по https, сервер и домен директор арендует сам (R09–R12). Директор не программист и ставит сервер по инструкции. Раунд 1, «ок»: российский VPS, Ubuntu 24.04, Caddy.

## Решение

Сервер и копии лежат на арендованном российском VPS (Ubuntu 24.04). Перед Node стоит Caddy: сам получает и продлевает сертификат Let's Encrypt, перенаправляет http на https и проксирует на `127.0.0.1:3000`; cookie сеанса помечается как только по https. Установка — скрипт `deploy/install.sh <домен>` и инструкция по-русски. Шрифты Manrope и JetBrains Mono скачаны один раз и встраиваются в страницу; страница не обращается ни к одному внешнему адресу, и демо-файл собирается той же сборкой.

## Почему

- **Свои сертификаты в Node или ручная выдача** — отвергнуто: директору не по силам, Caddy делает это без ручной работы.
- **Хостинг за рубежом** — отвергнут требованием 152-ФЗ из брифа: данные клиентов и сотрудников остаются в России.
- **Шрифты с Google Fonts** — отвергнуты: каждое открытие страницы — обращение к зарубежному сервису, а директор хочет быть уверен, что страница «не ходит в Google» (R25i: требование выведено из 152-ФЗ, раунд 1, «ок»).
- **Шрифты отдельными файлами рядом со страницей** — отвергнуты: нужна одна сборка и для сервера, и для демо, ноль внешних адресов в обоих; поэтому шрифты встроены в CSS.
- **Уведомления при закрытом браузере (Web Push)** — отвергнуто: нужны серверы Google и Apple, против 152-ФЗ (раунд 1, «ок»). Уведомления живут, пока открыта вкладка.

## Последствия

- Закрытый браузер — нет уведомлений. Дело, не замеченное вовремя, ждёт на экране.
- Домен и сервер ещё не арендованы: нет данных — имя домена и адрес сервера (R12 — заглушка). В инструкции стоят `<домен>` и `<IP-сервера>`.
- `deploy/install.sh` проверен только на синтаксис (`bash -n`): на машине сборки нет Linux. Первый настоящий запуск выполняет директор.
- Страница тяжелее: шрифты внутри файла увеличивают сборку и демо-файл.
- Сертификат зависит от доступности Let's Encrypt и правильной A-записи домена.
