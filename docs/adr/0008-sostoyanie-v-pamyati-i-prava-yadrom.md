# 0008. Сервер держит состояние в памяти и проверяет права кодом ядра прототипа

## Контекст

Права в прототипе во многих местах только прячут кнопки (задачи, товар, приёмка, юрлица, цены); часть проверок есть в ядре, часть — в видах. Ядро (`src/js` 31–44) не трогает DOM и `localStorage`, его уже исполняют тесты в `node:vm`. Фирма маленькая: десятки человек, мегабайты данных.

## Решение

Сервер при запуске загружает всё состояние фирмы из базы в память — один объект, как `S` прототипа, без личного. Правки применяются по одной в одном процессе. Код ядра сервер исполняет тем же приёмом, что тесты, и пользуется им: чтение урезает `Visible` (по `Leads.dealsVisible`, `Leads.visible`, видимости клиента и задачи, праву `prices`), запись проверяет `Guard` (по `Perms.can` и тем же функциям видимости). Экран и сервер считают одним кодом.

## Почему

- **Запросы к базе на каждый ответ** — отвергнуто: при таком объёме данных проще и надёжнее держать всё в памяти. Запросы потребовали бы вторую копию правил видимости на языке запросов — то, что правило проекта запрещает («величина живёт в одном месте»).
- **Доверять браузеру, как прототип** — отвергнуто: «запись, которую ему нельзя менять, сервер не принимает, даже если обойти кнопки» (R05.1), и сотрудник не получает чужого вообще (R05).
- **Отдельный свод прав для сервера** — отвергнут по тому же правилу: две копии одних прав разойдутся, как уже расходились получатели уведомлений.

## Последствия

- Сервер зависит от кода `src/js`: правка ядра меняет и экраны, и сервер. Обратная сторона: ошибка в видимости видна везде сразу (как в 0005).
- `Guard` — таблица правил, написанная вручную на каждый ключ данных. Она и есть то место, где права могут разойтись с интерфейсом; её проверяет единственное ревью сборки (R16).
- Один процесс: упал — все отключены до перезапуска; второй сервер для той же базы не поднять.
- Видимость считается заново и хранится по сеансу: сервер помнит, что уже отдал каждой вкладке, и шлёт разницу. Память растёт с числом вкладок.
- Рост данных за «десятки человек, мегабайты» потребует пересмотра. Нет данных: на каком объёме это станет заметно.
