# Как запустить CRM на своём компьютере

Инструкция для директора, без программирования. Подходит, пока своего сервера нет: CRM работает на вашем компьютере, открывается в браузере. Нужен только Node 24 (он у вас уже стоит; проверить — `node --version` в PowerShell, должно быть 24.x).

## Первый раз

1. Откройте PowerShell в папке с CRM: в проводнике зайдите в `D:\Claude\CRM`, в адресной строке напишите `powershell` и нажмите Enter.
2. Заведите директора (один раз на базу). Команда спросит имя, логин и пароль (не короче 8 знаков, при вводе он не виден), потом пароль ещё раз:

   ```powershell
   node server/admin.js create-director
   ```

   Логин запоминается маленькими буквами. Пароль нигде не записывается — не потеряйте его (забытый сбросит команда ниже).
3. Запустите сервер:

   ```powershell
   node server/main.js
   ```

   Появится строка «CRM запущена: http://127.0.0.1:3000». Окно не закрывайте: закроете — сервер остановится.
4. Откройте в браузере `http://127.0.0.1:3000` и войдите.

## Каждый день

Те же два действия: открыть PowerShell в папке `D:\Claude\CRM`, запустить `node server/main.js`, открыть адрес в браузере. Остановить — `Ctrl+C` в окне PowerShell. Данные при остановке не пропадают.

## Где лежат данные

Папка `data` рядом с программой: база `crm.db`, прикреплённые файлы `files`, ночные копии `backups` (каждую ночь в 03:00, хранятся 30 последних). Папка не попадает в git. **Копируйте `data` целиком**, если переносите CRM на другой компьютер.

Если вы раньше работали с CRM из другой папки (например из рабочей копии `D:\Claude\CRM\.claude\worktrees\server-crm-wind-solar-20828b`), её данные лежат в её собственной папке `data`. Чтобы продолжить с теми же сотрудниками и данными, скопируйте её в `D:\Claude\CRM`:

```powershell
Copy-Item -Recurse "D:\Claude\CRM\.claude\worktrees\server-crm-wind-solar-20828b\data" "D:\Claude\CRM\data"
```

Если папка `D:\Claude\CRM\data` уже есть, сначала посмотрите, нужна ли она: команда её не затирает, а вложит копию внутрь.

## Забыли пароль

```powershell
node server/admin.js reset-password логин
```

Команда покажет новый пароль один раз; при первом входе его надо будет сменить.

## Копии базы

```powershell
node server/admin.js backups
```

Показывает список копий. Скачать и восстановить копию можно и в самой CRM: «Настройки» → «Копии». Восстановление из командной строки: `node server/admin.js restore <имя копии> --yes` (перед этим снимается копия текущей базы; сервер потом перезапустите).

## Если нужен другой порт

```powershell
$env:CRM_PORT=5181; node server/main.js
```

и адрес `http://127.0.0.1:5181`. Переменная действует только в этом окне PowerShell.

## Чтобы коллеги в офисе заходили с своих компьютеров

Сервер по умолчанию слушает только ваш компьютер. Открыть его для офисной сети можно так:

```powershell
$env:CRM_HOST="0.0.0.0"; node server/main.js
```

Коллеги заходят по адресу `http://<IP вашего компьютера>:3000` (узнать IP: `ipconfig`, строка «IPv4-адрес»), а Windows спросит про доступ к сети — разрешите для частной сети. Учтите:

- пароли идут по сети без шифрования (https у такой схемы нет);
- ваш компьютер должен быть включён и сервер запущен, пока кто-то работает;
- копии базы лежат на этом же компьютере;
- со склада в другой сети такой адрес не откроется.

Для постоянной работы с несколькими сотрудниками из разных мест нужен настоящий сервер — см. `docs/server-install.md`.

## Обновление программы

**По кнопке (рекомендуется).** «Настройки → Обновить ПО» → «Проверить обновления» → «Обновить ПО». Сервер сам скачает последнюю версию с GitHub, сделает копию базы и перезапустится (около минуты, страница обновится сама). Чтобы он перезапускался сам, запускайте CRM **двойным щелчком по `start.cmd`** в папке с CRM (а не командой `node server/main.js`): тогда окно остаётся открытым и поднимает сервер после обновления. Данные и сотрудники не меняются; база сама доводится до новой формы.

Что важно: нужен интернет на этом компьютере; в папке не должно быть `.git` (это рабочая копия для разработки — её обновляют через git); версия, установленная кнопкой, записана в файле `.crm-version`. Если новая версия работает не так, прежний код лежит в папке `data/update-backup`, а копия базы до обновления — в «Настройки → Копии».

**Вручную.** Когда в папке заменили код руками, остановите сервер (`Ctrl+C`) и запустите снова.

## Если что-то не работает

- «CRM не запущена: …» — прочитайте текст в окне: чаще всего порт занят (запущена вторая копия — закройте её или возьмите другой порт).
- Страница не открывается — проверьте, что окно PowerShell с сервером не закрыто и в адресе нет опечатки.
- Вход не пускает после пяти неверных паролей — подождите 15 минут или сбросите пароль командой выше.
